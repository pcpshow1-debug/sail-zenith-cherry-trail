## Rules

1. The site is already built and deployed. Do **not** scaffold from the template.
2. Do **not** delete routes, components, public assets, `startup.sh`, or `AGENTS.md`.
3. Do **not** rebuild the homepage, router, or design system unless the user explicitly asks.
4. Only change what the current user message asks for.
5. GitHub `main` is the source of truth. Match production. Do not invent a new product.
6. Keep EN/RU copy in sync when you change user-facing text.
7. Estimator CTAs stay on https://estimate.rhinolab.app.
8. If a change is unclear, edit the smallest existing file. Do not start over.
